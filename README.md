# Job Desk

A small installable web app for running a job search: find jobs, tailor applications with any AI (Gemini, Grok, ChatGPT, Claude or a local model), track every application and follow-up, and get reminders.

Open it at the GitHub Pages address of this repository, then:

- **Android (Chrome):** menu → Install app
- **iPhone (Safari):** Share → Add to Home Screen

Your data stays on your device. Use *My profile → Back up all data* to move it to another device.
